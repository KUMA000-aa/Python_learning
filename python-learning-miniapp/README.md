# python-learning-miniapp

Python 学习小程序 —— **微信原生小程序前端**。

## 技术栈

- 微信原生小程序（无框架，直接 JS + WXML + WXSS）
- 与后端通过 HTTP + JWT 鉴权通信
- 接口请求统一封装在 `utils/request.js`

## 答题音效（`assets/audio/`）

连击与音效全部离线，不走网络：

| 文件 | 用途 |
|---|---|
| `correct_1..6.wav` | 答对音，音高沿五声音阶上行（C5→C6），连击 4+ 叠加高八度，6 连再加十二度 |
| `wrong.wav` | 答错，两声下行撞击 |
| `milestone.wav` | 每 5 连击的铃声（错开 70ms 叠在判对音之后） |

- 共 134 KB，16bit/22050Hz/单声道，由 `wave` 模块合成，无第三方音频库依赖
- 连击 ≥2 时顶部出现 🔥 胶囊、屏幕中弹出爆发提示；答错清零并提示「连击中断 ×N」
- 音量、静音开关状态存在 `sound_enabled`，答题页右上角 🔊 可随时切换
- **尊重系统静音键**（`obeyMuteSwitch` 默认 true），自习室不会外放
- 想换音色：替换同名 wav 即可，无需改代码

## 连击专属文案（`utils/combo-copy.js`）

连击除了数字和动画，还给一句「只属于这个连击」的话，避免每次都看到同一行字：

| 连击 | 档位 | 视觉 | 文案示例 |
|---|---|---|---|
| 2–3 | 连击开始 | 绿 | 连上了 / 有点东西 / 稳住能赢 |
| 4–5 | 状态很好 | 橙 | 越答越顺 / 进入状态 / 开始起飞 |
| 6–9 | 手感火热 | 深橙 | 根本停不下来 / 这题我熟 / 缩进都没错 |
| 10+ | 无人能挡 | 紫 | 出题人已退群 / 建议直接发证书 / bug 都绕着你走 |

- **里程碑专属句**：3 / 5 / 8 / 10 / 15 / 20 连各有一句独占文案（如「十连达成 · 出题人已退群，建议截图」），浮层额外加一圈白光
- **轮换机制**：同一档内的文案用「洗牌牌堆」抽取，一轮内不重复、跨轮不撞句
- **进度牵引**：浮层底部给「再 2 连 → 手感火热」，底部反馈条同步一句「再连对 2 题，进入…」
- **断连安慰**：4 句轮换，如「×7 断在这一题，思路还在，接着来」
- **结算评语**：按本次最高连击给一句总结（`bestComboCopy`），显示在结果页「最高连击」胶囊里
- 全量文案集中在 `TIERS` / `MILESTONES` / `BREAK_COPIES` 三个常量里，改文案不用动页面逻辑

想看效果：直接用浏览器打开项目根目录的 `combo-preview.html`，点「答对 +1」就能连点查看四档变化。

## 等级与头像框

经验、等级、头像框的数值全部由后端 `app/core/leveling.py` 决定，前端只负责展示：

| 位置 | 展示内容 |
|---|---|
| 首页顶部卡 | `Lv{level}` 徽章（底色 = 段位色）+ 段位小级「黑铁 Ⅲ」+ 经验条 |
| 结算页 | 经验卡：`+N EXP`（注明「通关 X + 探索 Y」）、经验条推进、升级横幅「Lv1 → Lv2 · 学徒」、新解锁头像框 |
| 我的页 | 头像外圈 = 当前头像框，头像下方 `Lv` 角标，昵称行「Lv3 · 黑铁 Ⅲ」，经验条按段位色，下面两行：「距 Lv4「黑铁 Ⅱ」还差 350 EXP」与「黑铁 再升 2 级晋级「青铜」」 |
| 我的页 · 头像框 | 8 个框的收藏格（每行 4 个）：已解锁可点击佩戴，未解锁显示 `Lv4 解锁` 并置灰加锁 |

- **经验只在首次闯关发放**：重复挑战同一关 `exp_gained = 0`，结算页会明确写「本关经验已领取，重复闯关不再增加」
- **经验 = 通关 + 探索**：通关 50/80/110/140（0–3 星）+ 答对题数 × 15，一关满分 185 EXP
- **等级曲线**：`need(lv) = 120 + 100×(lv-1) + 12×(lv-1)²`，前几级 120/232/368/528…，上限 Lv30。前段温和、后段跨度迅速拉开，Lv10 之后升一级要上千经验
- **段位**：每段 5 级 —— 黑铁 Lv1-5 / 青铜 6-10 / 白银 11-15 / 黄金 16-20 / 钻石 21-25 / 王者 26-30，称号形如「青铜 Ⅲ」（段内 Ⅴ→Ⅰ 递减，满级为「最强王者」）
- **跨段叫晋级**：结算横幅会区分「升级！Lv5 → Lv6」与「晋级！黑铁 → 青铜」，晋级卡加金色描边
- **头像框**：Lv1 素铁环 / Lv2 银纹环 / Lv4 金纹环 / Lv6 翡翠环 / Lv9 星轨环 / Lv12 传说之冠 / Lv16 星耀环 / Lv22 赤霄环
- **切换佩戴**走后端校验（`POST /profile/frame`），等级不够会返回 403，改前端参数没用

想看效果：浏览器打开项目根目录的 `level-preview.html`。

## 皮肤系统

一套皮肤 = 20 个色板令牌，由后端 `app/core/skins.py` 下发，前端只做两件事：

1. `utils/skin.js` 把令牌拼成 CSS 变量串（`--sk-primary` / `--sk-bg` …）；
2. 页面根节点挂 `class="page sk-root {{skinClass}}" style="{{skinStyle}}"`，WXSS 里全部写成 `var(--sk-primary, 兜底值)`。

所以**加一套皮肤不用改任何页面样式**，改后端 `SKINS` 列表就行。

| 皮肤 | 解锁 | 深色 | 说明 |
|---|---|---|---|
| 🌿 原野绿 | Lv1 默认 | 否 | 绿白搭配，最耐看 |
| 🌊 深海蓝 | Lv2 | 否 | 蓝青渐变，晚上推关很静 |
| 🌸 樱花粉 | Lv4 | 否 | 粉白 + 暖橙星星 |
| 📜 羊皮卷 | Lv6 | 否 | 牛皮纸底 + 棕墨主色 |
| 🌌 极光 | 全部关卡 3 星 | 否 | 限定款，紫到青的极光 |
| 🌃 赛博夜 | Lv9 | **是** | 深底 + 电光蓝，夜间专用 |
| 👑 曜金 | Lv13 | **是** | 黑底描金边 |

- 覆盖范围：页面底色与顶部氛围光、卡片、正文/次要文字、进度条槽、主色（按钮/选中态/进度）、hero 渐变、导航栏、底部 tabbar
- 深色皮肤额外给根节点加 `sk-dark`，未开始关卡那种「浅灰字」会自动提亮一档，避免深底上看不清
- 答题页的对错反馈色（绿✓/红✕）、星星金、连击橙**不跟皮肤走**，保证判题可读性
- 换肤走后端 `POST /profile/skin`，未解锁返回 403；等级款看 `min_level`，限定款看是否满星
- 换完皮肤会写本地缓存（`wx.setStorageSync('skin')`），切页面时先用缓存上色，不会先闪一下默认绿
- 我的页有皮肤色板缩略 + 「去皮肤图鉴挑一套」入口；结算页升级时会提示「解锁新皮肤」

想看效果：浏览器打开项目根目录的 `skin-preview.html`（支持 `?skin=cyber` 直链、`?only=detail` 只看对比）。

## 配置（首次使用必做）

打开 `utils/config.js`，改两个东西：

```javascript
// 后端地址：开发者工具里跑填 127.0.0.1，真机调试填电脑的局域网 IP
const BASE_URL = 'http://127.0.0.1:8001'

// 登录方式：没配 WX_APPID 时建议 true，保证每次都是同一个用户（进度不丢）
const USE_MOCK_LOGIN = true
const MOCK_CODE = 'dev_demo_user_001'  // 改成你自己的固定标识
```

**三种常见场景的 BASE_URL：**

| 场景 | BASE_URL |
|------|----------|
| 开发者工具模拟器 | `http://127.0.0.1:8001` |
| 手机真机调试（同 WiFi） | `http://192.168.x.x:8001`（cmd 跑 `ipconfig` 查） |
| 部署到服务器后 | `http://你的服务器IP:8001` 或 `https://你的域名` |

## 启动步骤

### 0. 先确保后端已经启动
详见 [项目根目录 README](../README.md)，后端启动在 `8001` 端口。

### 1. 导入微信开发者工具

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开 → **导入项目**
3. **目录** → 选择本文件夹 `python-learning-miniapp/`（⚠️ 不是仓库根目录）
4. **AppID** → 填你们自己的小程序 AppID，或点「测试号」
5. 导入成功后，在开发者工具里：
   - 点击右上角 **详情 → 本地设置**
   - ✅ 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**（开发阶段必勾，否则无法请求本地后端）

### 2. 编译运行

点击工具栏的 **编译** 按钮，左侧模拟器会显示首页。

## 鉴权机制

```
小程序启动 → wx.login() 拿 code → POST /auth/wx-login → 拿到 JWT token
    → 存本地（wx.setStorageSync）→ 所有请求自动带 Authorization: Bearer <token>
    → 401 时自动清 token，下次启动重新登录
```

- 没配 WX_APPID/WX_SECRET 时，后端自动走 mock 模式（用 code 当 openid）
- `USE_MOCK_LOGIN = true` 时不走 wx.login，直接用固定的 `MOCK_CODE`，保证每次都是同一个用户
- token 默认有效期 7 天

## 常见问题

**Q: 请求一直失败？**
A: 检查：① 后端是否在 8001 端口跑着；② `config.js` 的 BASE_URL 是否对；③ 本地设置里是否勾了"不校验合法域名"。

**Q: 每次打开都变成新用户，进度丢了？**
A: 把 `config.js` 的 `USE_MOCK_LOGIN` 改成 `true`，`MOCK_CODE` 设成你的学号或固定字符串，后端会用它当 openid，每次都是你。

**Q: 手机真机调试连不上后端？**
A: ① 手机和电脑必须连**同一个 WiFi**；② BASE_URL 改成电脑的局域网 IP（`ipconfig` 查 IPv4）；③ Windows 防火墙要放行 8001 端口（"Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建 TCP 规则，端口 8001，允许连接"）。

**Q: 想加新页面？**
A: 1. 在 `pages/` 下新建文件夹；2. 在 `app.json` 的 `pages` 数组里加路径；3. 微信开发者工具会自动识别。
